## Projects

### 1. Q-Learning: Epsilon-Greedy and Exploration Strategies
Introduction to Q-Learning, including epsilon-greedy action selection and exploration strategies.

### 2. Reinforcement Learning with Frozen Lake and Taxi
Application of reinforcement learning to the Frozen Lake and Taxi environments.

### 3. Supervised Learning: Gradient Descent with the Iris Dataset
Introduction to gradient descent using the Iris dataset for supervised learning.

### 4. SVM Classification: Iris and MNIST
Classification using hinge loss and Support Vector Machines (SVMs) on the Iris and MNIST datasets.

### 5. Spam Detection: Logistic Regression vs. Neural Network
Comparison of logistic regression and a neural network for spam email classification.
